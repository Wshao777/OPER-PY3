Security Policy

Supported Scope

Security reports should focus on:

- unauthorized Core access
- credential exposure
- unintended file access
- context boundary bypass
- unsafe automation
- data leakage

Do Not Publish Secrets

Never open an issue containing:

- passwords
- API keys
- access tokens
- cookies
- session data
- private personal information

Core Protection

OPER Core should remain isolated from unauthorized AI or external services.

Context Protection

Unexpected repository-wide access by an AI provider should be treated as a security issue.

Reporting

Please report security issues privately to the repository owner rather than publishing sensitive details in a public issue.

Security Principle

Protect:

Identity
Credentials
Core
Private Data
